# Research Methodology

This document describes the principles behind Market Recon’s research and data handling process.

## Methodology overview

1. Use only public data sources.
2. Record the original source and retrieval date.
3. Separate raw data from computed outputs.
4. Validate data quality before analysis.
5. Publish methodology and assumptions clearly.
6. Keep research educational and transparent.

## Reproducibility standards

- Save source URLs and retrieval timestamps
- Preserve raw files before transformation
- Document each transformation step
- Keep calculations transparent and repeatable
- Distinguish estimates from reported data

## Risk discipline

This project is not designed to produce investment advice. Research should be used to support learning, due diligence, and market understanding.

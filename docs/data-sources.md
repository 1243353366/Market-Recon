# Data Sources

This document lists the primary public data sources intended for use in the project.

## Core data sources

- SEC EDGAR
- Yahoo Finance
- Alpha Vantage
- Financial Modeling Prep
- Stooq
- Nasdaq public datasets
- FRED
- Trading Economics
- Investor relations pages
- Public earnings transcript archives

## Source provenance

Each dataset should maintain metadata about:

- Source name
- Retrieval URL
- Retrieval date
- API or file format
- Data coverage
- Known limitations

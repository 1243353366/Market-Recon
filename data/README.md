# Data

This directory stores raw and normalized public market data collected for research and archival purposes.

## Intended contents

- Equity price history
- Fundamental datasets
- Filing archives
- News and event data
- Derived feature tables
- Metadata and source mappings

## Data handling goals

- Preserve source provenance
- Track retrieval timestamps
- Maintain reproducible ingestion workflows
- Separate raw and processed artifacts

## Working principle

Every dataset should include metadata describing its source, retrieval date, and transformation pipeline.
